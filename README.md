## 🚀 Featured Projects

- **[AI Customer Support Assistant (RAG)](https://github.com/f-neves/ai-support-assistant)** · A retrieval-augmented customer support assistant built with Python, FastAPI, and Anthropic Claude. Features contextual retrieval using a SQLite-based vector store with sqlite-vec, streaming responses over SSE, an embeddable React chat widget, an administrative dashboard with CSAT and resolution metrics, and confidence-based escalation to human support.

- **[AI Email Support Autoresponder](https://github.com/f-neves/ai-email-support)** · An AI-assisted email support workflow combining automated classification with human-reviewed response generation. Uses Claude Haiku for structured classification and Claude Sonnet for reply drafting, with Gmail synchronization, Node.js, Fastify, Prisma, React, and prompt caching to reduce costs on repeated context.
